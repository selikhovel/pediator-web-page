# Дизайн-система

Источник: визуальное оформление аккаунта @pediatr_39. Задача — перенести узнаваемость
блога на сайт, но снизить агрессивность: в ленте резкость работает на охваты,
на лендинге она мешает записаться на приём.

---

## 1. Цвет

| Токен | HEX | Роль |
|---|---|---|
| `bordeaux` | `#4A0D18` | Основной тёмный фон: hero, CTA-полосы, футер |
| `bordeaux-deep` | `#2E0710` | Текст на светлом, границы, тени |
| `crimson` | `#D81E2C` | Акцент: кнопки, подчёркивания, ключевые цифры, дисплейный текст |
| `crimson-ink` | `#C81627` | Тот же акцент, но для мелкого текста на светлом фоне |
| `rose` | `#E9718F` | Pill-бейджи, hover-состояния |
| `blush` | `#FBE5EA` | Светлые секции, карточки услуг |
| `bone` | `#EDEAE5` | Основной фон читаемых секций |
| `white` | `#FFFFFF` | Текст на bordeaux, фон статей |

**Пропорция.** Лента почти целиком бордовая — сайт так делать нельзя, длинный текст
на тёмном не читается. Ориентир: `bone`/`white` ≈ 60% высоты страницы,
`bordeaux` ≈ 30% (hero, разделительные полосы, футер), `blush` ≈ 10%.

**Контраст (обязательно к соблюдению).** Все числа ниже измерены по WCAG 2.1,
не прикинуты на глаз. Порог: 4.5:1 для текста мельче 24px (или 18.7px жирного),
3:1 для крупного текста и для нетекстовых границ.

| Пара | Ratio | Где можно |
|---|---|---|
| `crimson` на `white` | 5.07 | любой текст |
| `crimson` на `bone` | **4.23** | только текст от 24px и декор |
| `crimson` на `blush` | **4.22** | только текст от 24px и декор |
| `crimson` на `bordeaux` | **3.04** | только дисплейный текст от 32px и декор |
| `crimson-ink` на `bone`/`blush` | 4.86 | любой текст |
| `rose` на `bordeaux` | 5.30 | любой текст, но только на этом фоне |
| `rose` на `bone`/`blush` | **2.42** | нигде, даже крупно |
| `white` на `crimson` | 5.07 | любой текст (кнопка `.btn-p`) |
| `bordeaux-deep` на `bone` | 15.17 | основной текст |

Отсюда три правила, которые нарушаются чаще всего:

- **Мелкий акцентный текст на `bone` и `blush` — это `crimson-ink`, не `crimson`.**
  Разница в цвете почти не видна, разница в проходимости AA — принципиальная.
  Типичный случай: подписи регалий в блоке «О враче», 14px uppercase.
- **`rose` как цвет текста живёт только на `bordeaux`.** Там он даёт 5.30 и
  спасает мелкие акценты на тёмном, где `crimson` проваливается. На светлом фоне
  `rose` — исключительно заливка и границы.
- **Для кнопок на тёмном** — `white` фон + `bordeaux` текст, не `crimson`.

Квадратные скобки `<Bracket>` — это текст, а не декор: на тёмном фоне они
красятся в `rose`, на светлом в `crimson` (крупно) или `crimson-ink` (мелко).

## 2. Типографика

Две гарнитуры. Третья — только для рукописных пометок, не чаще двух раз на страницу.

- **Дисплей:** Oswald 600/700. Узкий гротеск, плотный трекинг (`-0.01em`), верхний регистр.
  Бесплатный аналог Druk Cyrillic из ленты. Если у врача есть бюджет на шрифт —
  Druk Cyrillic Condensed даст точное попадание, заложи это отдельной строкой в КП.
- **Текст:** Golos Text 400/500/600. Открытая кириллица от Paratype, отлично читается
  с телефона.
- **Рукописный акцент:** Caveat 400. Только для коротких реплик на полях
  («листайте», «тут про меня»). Не для заголовков, не для подписей к услугам.

Все шрифты **самохостить** через `@fontsource` (`astro:assets` — это про изображения,
к шрифтам он не относится). Google Fonts из РФ грузится нестабильно — это прямой
удар по LCP. В `reference/index.html` шрифты подключены с CDN: это сделано, чтобы
эталон открывался двойным кликом, и переносить такое подключение нельзя.

**Шкала** (мобильный / десктоп):
```
display-xl   40 / 72   Oswald 700, uppercase, line-height 0.95
display-l    30 / 48   Oswald 700, uppercase, line-height 1.0
heading      22 / 30   Oswald 600, sentence case
body-l       18 / 20   Golos Text 400, line-height 1.6
body         16 / 17   Golos Text 400, line-height 1.65
caption      14 / 14   Golos Text 500
```

Длина строки в статьях — не больше 68 символов (`max-w-[34rem]`).

## 3. Фирменные приёмы

Пять приёмов из ленты. Больше не добавлять — каждый следующий размывает узнаваемость.

**3.1. Квадратные скобки.** Главный маркер бренда: `[давайте знакомиться]`,
`мои [принципы] работы`. Компонент `<Bracket>` — скобки рисуются как отдельные
элементы цветом `crimson`, содержимое наследует цвет текста.

**3.2. Двухголосый заголовок.** Тяжёлый узкий верхний регистр + строка светлым
курсивом рядом. Это осознанное отступление от правила «не выделять одно слово
в заголовке» — приём взят из брифа и работает на узнаваемость.

```
КУДА ВЫ ПОПАЛИ?
[давайте знакомиться]
```

**3.3. Чёрно-белая фотография.** Все портреты и кадры с приёма — `grayscale(1)`.
Цвет на сайте живёт только в типографике и плашках. Единственное исключение —
клинические фото (сыпь, кожа) в статьях: там цвет несёт информацию.

**3.4. Pill-бейджи.** Скруглённые плашки в стиле шапки постов: `врач-педиатр`,
`выезд на дом`, `онлайн-консультация`. Фон `blush` или `white`, текст `bordeaux`,
`border-radius: 999px`, padding `6px 14px`. Работают как теги услуг и как навигация
по статьям.

**3.5. Зачёркивание.** В ленте — риторический приём. На сайте использовать только
там, где зачёркивание несёт смысл: блок «мифы о детском здоровье», где зачёркнутый
миф сменяется фактом. Как декор — не применять.

Звёздочки-искры и сетка-разметка поверх фото: максимум один такой элемент на экран.

## 4. Тон текста

Заголовки в ленте намеренно провокационные («Я вам ничего не должна»). На сайте
провокация остаётся только в разделе статей — там она приводит трафик. Hero,
услуги, контакты пишутся спокойно: родитель на этой странице уже встревожен
болезнью ребёнка, ему нужна ясность, а не полемика.

Сохраняем: прямоту, отсутствие канцелярита, обращение на «вы» без заискивания.
Убираем: восклицательные знаки, капслок в основном тексте, обещания результата.

## 5. Что проверять перед сдачей

- [ ] Контраст всех текстовых пар ≥ 4.5:1 (AA), крупный дисплейный ≥ 3:1 —
      сверяться с таблицей в §1, а не на глаз
- [ ] Нетекстовый контраст ≥ 3:1: границы плашек, рамки полей, иконки-ссылки
- [ ] Смысл, переданный только начертанием (зачёркивание, цвет), продублирован
      текстом — иначе он не доедет до скринридера
- [ ] Читается при 200% зуме и в горизонтальной ориентации
- [ ] Видимый фокус на всех интерактивных элементах
- [ ] `prefers-reduced-motion` уважается
- [ ] Шрифты самохостятся, `font-display: swap`
- [ ] Дисклеймер о противопоказаниях и данные лицензии в футере
- [ ] Ни одного фото пациента без письменного согласия родителей
