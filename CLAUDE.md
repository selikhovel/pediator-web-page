# Сайт-визитка врача-педиатра

Лендинг для частнопрактикующего педиатра. Русский язык, аудитория — родители
детей от 0 до 17, регион России. Делается как коммерческое предложение: врач
ещё не заказчик, сайт должен продать сам себя на встрече.

Врач активно ведёт соцсети. Визуальная идентичность сайта взята из оформления
её ленты — см. `docs/design-system.md`, это не рекомендация, а спецификация.

## Стек

- Astro (последняя стабильная), статическая сборка, без SSR
- Tailwind CSS
- TypeScript, strict
- Content Collections для всего контента
- `@astrojs/sitemap`
- Шрифты через `@fontsource` — самохостинг обязателен

Без React, Vue и прочих островов. Если кажется, что нужен клиентский фреймворк —
сначала спроси, почти наверняка не нужен.

## Жёсткие правила

1. **Никакого контента в компонентах.** Все тексты, цены, регалии, услуги живут
   в `src/content/`. Компонент принимает данные пропсами. Хардкод строки в `.astro` —
   это баг, даже если она выглядит технической.
2. **Плейсхолдеры видимы.** Незаполненные данные рендерятся с классом `.ph`
   (красный пунктир). Это опросник для встречи с врачом. Не подставляй
   правдоподобные выдумки вместо плейсхолдера — стаж, цены и номер лицензии
   выдумывать нельзя категорически.

   Две формы записи в yaml, других нет:
   ```yaml
   name: "PH::Фамилия Имя Отчество"        # не заполнено значение целиком
   badge: "стаж {{00}} лет"                # не заполнена часть строки
   ```
   Компонент `<Ph>` разбирает обе. Если строка начинается с `PH::`, фигурные
   скобки внутри неё не разбираются. Префикс `PH::` в вёрстку не попадает.
3. **Формы не делаем.** На этом этапе сайт не собирает персональные данные:
   нет формы, нет 152-ФЗ, нет обязательного российского хостинга. Контакты —
   только `tel:` и ссылки на мессенджеры.
4. **WhatsApp не используем.** Заблокирован в РФ с февраля 2026. Telegram —
   с оговоркой о нестабильности. Основной текстовый канал — ВКонтакте.
5. **Instagram не встраиваем.** Эмбеды не загрузятся у российских посетителей.
   При упоминании в тексте — с оговоркой о статусе Meta.
6. **Фото пациентов — только с письменным согласием родителей.** Пока согласий
   нет, в макете стоят плейсхолдеры. Не подставляй стоковые снимки детей.
7. **Юридический футер обязателен** на всех страницах: предупреждение о
   противопоказаниях, данные лицензии, оговорка о справочном характере.
   Лицензия у самого врача (частный кабинет), не у клиники — значит обязанности
   исполнителя платных медуслуг лежат на этом сайте, а не на чужом. Подробности
   в `docs/sections.md`, раздел про сведения об исполнителе.
8. **Изображения — только через `astro:assets`.** Портреты и кадры с приёма —
   `grayscale(1)`. Исключение: клинические фото в статьях, там цвет информативен.
9. **Смысл не передаётся одним начертанием.** Зачёркивание, цвет и иконка —
   всегда с текстовым дублем, иначе информация не доедет до скринридера.
   Контраст сверяй по таблице в `docs/design-system.md` §1, а не на глаз:
   мелкий акцентный текст на светлом — это `crimson-ink`, а не `crimson`.

## Команды

```
npm run dev        # локальный сервер
npm run build      # прод-сборка
npm run check      # astro check + tsc
npm run shot -- <section>   # скриншот секции, 360px и 1440px, в .screens/
```

## Как работаем

Одна секция — одна задача — один коммит. Между секциями `/clear`: на длинном
контексте вёрстка деградирует.

После каждой секции — `npm run shot`, прочитай получившийся PNG и раскритикуй
сам. Верстать вслепую нельзя, особенно hero. Опорный вьюпорт — 360×640: он
жёстче всего, что встречается на практике, и покрывает iPhone SE.

Референс внешнего вида — `reference/index.html`. Это готовый одностраничник,
собранный вручную. Не переписывай его дизайн, переноси. Отличия допустимы там,
где Astro даёт что-то лучше (изображения, семантика), не там, где хочется
«сделать красивее».

## Карта проекта

```
docs/design-system.md   цвета, шрифты, фирменные приёмы, чек-лист сдачи
docs/sections.md        роль каждой секции и её данные
reference/index.html    визуальный эталон
src/content/doctor.yaml все данные врача (сейчас плейсхолдеры)
scripts/shot.mjs        скриншоты
```

## Тон текстов

В ленте врач резкая и полемичная — на охваты это работает. На сайте провокация
остаётся только в блоке «Что я делать не буду» и в заголовках статей. Hero,
услуги, контакты пишутся спокойно: на страницу приходит встревоженный родитель.

Запрещено: восклицательные знаки, капслок в тексте, «лучший», «гарантируем»,
«избавим», любые обещания результата. Обращение на «вы» без заискивания.
